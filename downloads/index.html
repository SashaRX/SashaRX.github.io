Install & upgrade

MAX ModelBatch

  1. Save your scene and close Max.
  2. Extract the ZIP for your exact Max year into a permanent folder.
  3. Add the MaxModelBatch.dlu folder in Customize → Configure System Paths → 3rd-Party Plug-Ins.
  4. Restart Max and open MAX ModelBatch from the menu.

When upgrading from TS_UnityExport.dlu, remove the old copy from scanned plugin folders. Do not copy additional Qt DLLs.

FBX Patch Tool

  1. Extract the archive and open PowerShell in the tool folder.
  2. .\patch_fbx.exe --version
  3. Build an audit command and inspect one folder first.
.\patch_fbx.exe -r -v --report-file audit.md "D:\Models"

Release notes

MAX ModelBatch 1.3.11

Hidden faces do not contribute seam lines or checker triangles. In Edge/Border sub-object mode, selected edges keep their native selection color: seam lines and chains omit these edges, while statistics still count them. Changing the edge selection refreshes the overlay. This applies to Editable Poly, Edit Poly, Editable Mesh and Edit Mesh.

FBX Patch Tool 1.1.1

Opt-in strict channel normalization, missing-smoothing recovery and collision cleanup. Missing UV1 copies UV0. Verified on generated SDK fixtures; strict rewrites change FBX object IDs. Native Unity/Max behavior remains unverified.
