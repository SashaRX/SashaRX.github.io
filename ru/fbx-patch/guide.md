# FBX Patch Tool 1.0.1

Полный справочник команд для Windows x64. Работает без Max, Unity и Qt.

Программа проверяет и исправляет существующие FBX: материалы, текстуры, UV, вершинные цвета, коллизии, нормали, сглаживание, единицы, оси, геометрию и метаданные. Несколько файлов и папок можно обработать одним запуском.

Скачать: https://github.com/SashaRX/MaxModelBatch-Releases/releases/tag/patch-fbx-v1.0.1

## Начало работы

Распакуй ZIP и открой PowerShell рядом с patch_fbx.exe. Это консольная программа. Пути с пробелами и кириллицей поддерживаются; каждый путь заключай в кавычки.

```powershell
.\patch_fbx.exe --version
.\patch_fbx.exe --help
.\patch_fbx.exe -r -v --report-file audit.md "D:\Models"
.\patch_fbx.exe --inspect "D:\Models\SM_Chair.fbx"
.\patch_fbx.exe -n -r --strip-tbn --strip-col-data "D:\Models"
```

Без параметров исправления выполняется только аудит. -n показывает план и не пишет FBX/backup; --inspect всегда только читает. Отчёт --report-file может записываться и в режиме -n.


Общая diffuse-текстура у мешей с разными именами UV0 отмечается как UVSET-CONFLICT. Её UVSet сохраняется. Для исправления приведи имена UV0 к общему виду в исходной сцене либо раздели привязки текстур/материалов.

## Все 62 пользовательских параметра

### Запуск и вывод

| Параметр | Действие |
|---|---|
| `--recursive` / `-r` | Обходить вложенные папки. Без параметра сканируется только верхний уровень. |
| `--dry-run` / `-n` | Показать план выбранных исправлений без записи FBX и резервных копий. Отчёт может записываться. |
| `--inspect` | Показать содержимое сцены, мешей и материалов. Всегда только чтение; исправления, процессы и запись отчёта обходятся. |
| `--report-file PATH` | Записать UTF-8 отчёт по категориям проблем: .md — Markdown, другое расширение — обычный текст. Существующий отчёт перезаписывается. |
| `--jobs N` / `-j` | Число параллельных процессов: один FBX на процесс. По умолчанию — автоматически по CPU, максимум 64; -j 1 обрабатывает последовательно. |
| `--verbose` / `-v` | Показывать результат для каждого файла, а не только сводку. При параллельной обработке строки могут чередоваться. |
| `--short-paths` | Сократить пути в выводе начиная с первой папки Assets или Content. Входные пути и файлы не изменяются. |
| `--no-backup` | Не создавать стандартную .fbx.bak при перезаписи. Это не превращает исправление в режим чтения. |
| `--help` / `-h` | Вывести полную встроенную справку и завершиться с кодом 0. Входной путь не нужен. |
| `--version` | Показать версии программы и встроенного FBX SDK и завершиться. Входной путь не нужен. |

### Материалы

| Параметр | Действие |
|---|---|
| `--apply-materials-patch` | Включить шейдинг render-мешей, заполнить пустые относительные пути текстур и привязать diffuse к UV0. Конфликтующие общие привязки отмечаются и сохраняются. По умолчанию исправления выключены. |
| `--fix-mat-layers` | Исправить слои материалов render-мешей: перенести корректное назначение в слой 0 и убрать заглушки eNone. Геометрические каналы сохраняются. |
| `--upgrade-material-to-phong` | Преобразовать Lambert и общие материалы в Phong с сохранением имени, diffuse и его текстуры; specular/reflection обнуляются. |
| `--create-default-material-from-pool` | Создать Phong для render-мешей без материала на основе самой частой записи пула. Нужны --material-pool и подходящий материал-донор среди входных FBX. |

### Текстуры и пул материалов

| Параметр | Действие |
|---|---|
| `--guess-textures` | Найти отсутствующий diffuse по имени материала, например M_Chair → T_Chair_Albedo. Поиск в папке FBX, соседних Textures, зеркальных путях Meshes/Textures и указанном корне текстур. |
| `--texture-root PATH` | Дополнительная папка текстур с рекурсивным индексом для --guess-textures. Дополняет поиск рядом с FBX. |
| `--rebind-missing-textures` | Повторно найти diffuse для существующих подключений с нерабочими путями. Требует --guess-textures; без него перепривязка не выполняется. |
| `--material-pool` | Сначала собрать пул из всех входных FBX: самая частая diffuse-текстура для каждого имени материала. Используется --guess-textures или --create-default-material-from-pool; добавляет проход анализа. |
| `--debug-textures` | Печатать имена кандидатов для материалов без найденной текстуры. Требует --guess-textures; режим предпросмотра позволяет проверить поиск без записи. |

### UV-каналы

| Параметр | Действие |
|---|---|
| `--clamp-uv1` | Ограничить второй UV-канал (индекс FBX 1) диапазоном [0, 1]. Координаты вне диапазона теряются; развёртка не создаётся. |
| `--clamp-uv2` | Ограничить третий UV-канал (индекс FBX 2) диапазоном [0, 1]. Не создаёт развёртку и не пакует острова. |
| `--fill-missing-uv1` | Добавить render-мешам отсутствующий второй UV-канал с постоянным (1, 1). Это данные для шейдера, а не генерация lightmap-развёртки. |
| `--fill-missing-uv2` | Добавить render-мешам отсутствующий третий UV-канал с постоянным (1, 1). Существующий UV2 сохраняется. |
| `--uv2-y-zero` | При создании канала через --fill-missing-uv2 использовать (1, 0) вместо (1, 1). Существующий UV2 не меняется. |
| `--strip-broken-uv-layers` | Убрать пустые или повреждённые UV-элементы и таблицы индексов. Выполняется до заполнения отсутствующих UV; действует и на коллизии. |

### Вершинные цвета

| Параметр | Действие |
|---|---|
| `--fill-missing-vcolor` | Заполнить отсутствующие вершинные цвета белым непрозрачным RGBA (1, 1, 1, 1). |
| `--clamp-vcolor` | Ограничить существующие компоненты RGBA вершинных цветов диапазоном [0, 1]. |
| `--strip-extra-vcolor-layers` | Оставить один слой вершинных цветов на render-мешах. Если слой 0 пуст, сначала сохранить в нём первый непустой верхний слой, затем убрать лишние. |

### Коллизии

| Параметр | Действие |
|---|---|
| `--strip-col-data` | Убрать UV и вершинные цвета коллизий. Данные, общие с render-мешами, сохраняются. Геометрия коллизий не удаляется. |
| `--strip-col-mat-layers` | Исправить повреждённые заглушки слоёв материалов именно на коллизиях, которые пропускает --fix-mat-layers. |
| `--replace-col-placeholder-materials` | Заменить заглушки Lit/Default/Material коллизий материалом render-меша из того же FBX. Без подходящего донора замена не выполняется. |

### Нормали, сглаживание и тангенты

| Параметр | Действие |
|---|---|
| `--detect-broken-normals` | Найти отсутствующие, нечисловые или почти нулевые нормали render-мешей. Не перестраивает их. |
| `--detect-missing-smoothing` | Найти отсутствие сглаживания в слое 0 или полностью нулевые группы, где все рёбра жёсткие. |
| `--detect-faceted-normals` | Сравнить нормали углов с геометрическими нормалями граней и выявить плоское сглаживание. Задуманные жёсткие рёбра не меняет. |
| `--detect-broken-tbn` | Найти render-меши с явными тангентами и смешанным направлением UV — возможную проблему знака на зеркальных островах. Это не общая проверка всех тангентов. |
| `--strip-tangents-binormals` / `--strip-tbn` | Удалить слои тангентов и бинормалей для пересчёта при импорте. Нормали, сглаживание и UV сохраняются. |
| `--bake-tangents` / `--bake-tbn` | Создать тангенты/бинормали FBX SDK по UV0 с ignoreTangentFlip=true; коллизии пропускаются. При совместном выборе удаление выполняется раньше. В Unity использовать Tangents: Import. |
| `--rebuild-normals-from-smoothing` | Пересчитать нормали углов render-мешей по существующим группам сглаживания полигонов. Без слоя сглаживания не работает. |
| `--rebuild-shading` | Использовать корректные группы сглаживания либо восстановить их по совпадающим нормалям углов, затем пересчитать нормали. Нужны пригодные данные сглаживания или нормалей. |
| `--rebuild-shading-from-uv` | Восстановить сглаживание по островам UV0: UV-швы становятся жёсткими границами, затем пересчитываются нормали. Подходит, когда UV-швы соответствуют задуманным границам сглаживания. |
| `--fix-normal-w` / `--zero-normal-w` | Обнулить однородную компоненту W у нормалей. Компоненты XYZ не пересчитываются. |

### Единицы и трансформации

| Параметр | Действие |
|---|---|
| `--convert-to-meters` | Перевести системные единицы сцены в метры через FBX SDK. Для единичного масштаба узлов можно дополнить запеканием scale. |
| `--bake-non-identity-scale` | Запечь накопленный scale в вершины и позиции детей, сбросить локальный scale в (1, 1, 1). Неравномерный scale родителей с поворотом может дать сдвиг формы; pivot и Geometric* не запекаются. |
| `--bake-geometric-transforms` | Запечь FBX GeometricTranslation/Rotation/Scaling в вершины меша и сбросить эти свойства. Это отдельная операция от локального Transform узла. |
| `--detect-negative-scale` | Найти накопленный scale с отрицательным определителем: нечётное число перевёрнутых осей. Порядок вершин полигонов не исправляет. |

### Оси

| Параметр | Действие |
|---|---|
| `--detect-broken-axis` | Проверить заголовок осей/единиц и отсутствующие отметки конвертации. Сообщает о подозрительных метаданных, но не конвертирует сцену. |
| `--detect-axis-mismatch` | Сравнить геометрические и записанные нормали render-мешей для поиска несогласованности координат. Это эвристика, а не доказательство исходной системы осей. |
| `--fix-axis-system` | Исправить поддерживаемые ошибки заголовка/данных осей и привести к Y-up. Автоматически включает обе проверки осей. Меняет трансформации, вершины и нормали; внимательно проверить предпросмотр. |

|---|---|

### Имена и диагностика источника

| Параметр | Действие |
|---|---|
| `--restore-mesh-names-from-node` | Заменить общие имена атрибутов мешей (Scene, Geometry, Mesh и т. п.) именем владеющего узла. Сам узел не переименовывается. |
| `--restore-texture-names-from-file` | Заменить стандартные имена объектов текстур вроде DiffuseColor_Texture именем файла без расширения. Файлы текстур не переименовываются. |
| `--detect-non-ascii-names` | Найти кириллицу/CJK, недопустимые для Windows и управляющие символы в именах, каналах и путях текстур. Проверка совместимости пайплайна, а не качества имён. |
| `--detect-modified` | Отметить пустые/отсутствующие метаданные приложения как возможное пересохранение. Не доказывает факт редактирования. |
| `--detect-unity-modified` | Найти Unity в метаданных исходного или последнего сохранявшего приложения/производителя. |
| `--classify-source` | Сгруппировать по метаданным источника: пусто, Blender, стандартные Max/Maya, Unity FBX, собственный Max SDK или другое приложение. Добавляет категории SOURCE-* в отчёт. |

## Служебные аргументы

Диспетчер также принимает три служебных аргумента: --child-mode STATS_PATH (процесс исправления одного файла), --survey-mode STATS_PATH (процесс анализа пула без записи FBX), --load-material-pool PATH (пул, подготовленный диспетчером). Это внутренний протокол, а не обычные команды обработки библиотеки; в конструктор они не включены.

## Каналы, порядок операций и резервные копии

UV0/UV1/UV2 — индексы FBX 0/1/2, соответствующие map-каналам Max 1/2/3. Заполнение UV постоянным значением не создаёт развёртку. Коллизии распознаются по _COL, _Collider, _Collision без учёта регистра и с числовыми хвостами.

Порядок флагов в строке не задаёт порядок исправлений. Программа задаёт его сама: оси до единиц и операций над мешами; удаление TBN до запекания; исправление сглаживания по UV до общего rebuild-shading. rebuild-shading-from-uv должен соответствовать задумке жёстких рёбер.

Успешная перезапись создаёт .fbx.bak, следующая перезапись обновляет копию. Аудит, -n и операции без изменений её не трогают. --no-backup отключает копию. FBX SDK пересохранение не идентично входному файлу побайтно.

Коды: 0 — выполнение завершено (находки сами по себе не ошибка), 1 — ошибка командной строки/нет пригодных входов, 2 — ошибка хотя бы одного файла.
