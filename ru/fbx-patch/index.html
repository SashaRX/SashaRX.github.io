FBX Patch Tool

Консольный инструмент для проверки и исправления целых библиотек FBX: материалы и текстуры, UV и цвета, коллизии, нормали, сглаживание, масштаб, оси и очистка сцены. Обрабатывает несколько файлов и папок за один запуск; Max, Unity и Qt не нужны.

Сценарий: аудит библиотеки FBX →

1. Начало работы

  1. Скачай и распакуй ZIP.
  2. Открой PowerShell в папке с patch_fbx.exe.
  3. Проверь версию и доступные команды:
.\patch_fbx.exe --version
.\patch_fbx.exe --help

Это консольная программа. Двойной клик по EXE не открывает графический интерфейс. В примерах указаны условные пути — замени их своими. Пути с пробелами заключай в кавычки. Можно передавать несколько файлов и папок, в том числе с кириллицей в путях.

2. Команды

Исправления включаются явно: без флагов исправлений программа только сообщает о найденных проблемах. Начни с аудита, затем проверь нужные изменения с помощью -n. При применении соответствующие FBX перезаписываются на месте.

Известная проблема версии 1.0.0. Применение исправления может завершиться ошибкой staged export is no longer the file that was validated и кодом 2. Сбой воспроизведён с --strip-tbn --strip-col-data; примеры аудита и предпросмотра прошли проверку. До исправления используй аудит и предпросмотр. При этой ошибке сохрани файл .bak.tmp, если он указан в сообщении.

Готовые примеры · 11 типовых команд

Проверить папку моделей

Проверка всех вложенных папок, вывод результатов по файлам и отчёт Markdown. Флаги исправлений не включены, поэтому FBX остаются без изменений.

.\patch_fbx.exe -r -v --report-file audit.md "D:\Models"

Посмотреть содержимое одного FBX

Просмотр данных сцены, мешей и материалов. Этот режим всегда оставляет FBX без изменений, даже если переданы флаги исправлений.

.\patch_fbx.exe --inspect "D:\Models\SM_Chair.fbx"

Предпросмотр очистки коллизий и тангенсов

Показать планируемые исправления без записи FBX и резервных копий: удалить тангенсы/бинормали и UV/цвета вершин у мешей коллизий.

.\patch_fbx.exe -n -r --strip-tbn --strip-col-data "D:\Models"

Применить проверенную очистку

Та же команда без -n применяет найденные исправления в исходных файлах. Для каждого перезаписанного FBX по умолчанию создаётся копия .fbx.bak.

.\patch_fbx.exe -r --strip-tbn --strip-col-data "D:\Models"

Предпросмотр исправлений данных материалов

Включить отображение текстур, заполнить пустые относительные пути текстур и привязать diffuse-текстуры к первому UV-каналу. Для применения убери -n после проверки.

.\patch_fbx.exe -n --apply-materials-patch "D:\Models\SM_Chair.fbx"

Предпросмотр поиска текстур

Найти недостающие diffuse-текстуры по соглашению имён материалов и текстур, например M_Chair и T_Chair_Albedo, в указанной папке текстур.

.\patch_fbx.exe -n --guess-textures --texture-root "D:\Textures" "D:\Models\SM_Chair.fbx"

Предпросмотр ограничения lightmap UV

Ограничить UV1, второй UV-канал, диапазоном [0, 1]. Координаты за пределами диапазона теряются; команда не создаёт развёртку и не упаковывает острова.

.\patch_fbx.exe -n --clamp-uv1 "D:\Models\SM_Chair.fbx"

Предпросмотр исправлений цветов вершин

Заполнить отсутствующие цвета вершин непрозрачным белым и ограничить существующие RGBA диапазоном [0, 1]. Для применения убери -n после проверки.

.\patch_fbx.exe -n --fill-missing-vcolor --clamp-vcolor "D:\Models\SM_Chair.fbx"

Предпросмотр перевода в метры

Перевести единицы сцены в метры и запечь компенсирующий масштаб узлов в геометрию. Для применения убери -n после проверки.

.\patch_fbx.exe -n --convert-to-meters --bake-non-identity-scale "D:\Models\SM_Chair.fbx"

Предпросмотр очистки геометрии

Удалить неиспользуемые вершины и вырожденные полигоны. Для применения убери -n после проверки.

.\patch_fbx.exe -n --remove-orphan-vertices --remove-degenerate-polys "D:\Models\SM_Chair.fbx"

Обработать несколько путей четырьмя процессами

Проверить файл и папку за один запуск, включая вложенные папки. -j 4 ограничивает параллельную обработку четырьмя рабочими процессами.

.\patch_fbx.exe -r -j 4 --report-file audit.md "D:\Models\SM_Chair.fbx" "D:\Models\Props"

Служебные аргументы процессов

Диспетчер также принимает три служебных аргумента: --child-mode STATS_PATH (процесс исправления одного файла), --survey-mode STATS_PATH (процесс анализа пула без записи FBX), --load-material-pool PATH (пул, подготовленный диспетчером). Это внутренний протокол, а не обычные команды обработки библиотеки; в конструктор они не включены.

Каналы определяются по порядку элементов FBX, а не по именам. --fill-missing-uv1 и --fill-missing-uv2 добавляют постоянные значения (1, 1), а не создают lightmap-развёртку. --uv2-y-zero меняет значения добавляемого UV2 на (1, 0).

Очистка коллизий распознаёт суффиксы _COL, _Collider и _Collision без учёта регистра, в том числе с числовым хвостом вроде _Collider_26. --strip-col-data удаляет UV и цвета вершин у коллизий, сохраняя данные, общие с render-мешами.

5. Резервные копии

По умолчанию при каждой успешной перезаписи создаётся <файл>.fbx.bak, например SM_Chair.fbx.bak. Следующая перезапись обновляет эту копию. Аудит, предпросмотр и исправления без фактических изменений не трогают FBX и его резервную копию.

Для отмены исправления скопируй резервную копию поверх FBX или восстанови её под новым именем с расширением .fbx. Флаг --no-backup отключает создание копий. Ограничение диапазонов и очистка могут удалять данные — проверяй предпросмотр перед применением.

Сохранение через FBX SDK не сохраняет побайтовое совпадение с исходным файлом. Утилита работает с FBX; вывод GLB и meshopt в ней отсутствует.
