WINDOWS X64 · ВЕРСИЯ 1.0.0 · КОМАНДНАЯ СТРОКА

FBX Patch Tool

Проверка и исправление библиотек FBX: материалы, текстуры, UV-каналы, данные коллизий, нормали и единицы измерения. Работает отдельно от 3ds Max и Unity.

Конструктор команд и справка → Скачать ZIP ↓

Распакуй архив и запусти patch_fbx.exe из PowerShell. Начни с аудита или предпросмотра исправлений через --dry-run.

Скачивание с GitHub сейчас требует доступа к приватному репозиторию MaxModelBatch.
